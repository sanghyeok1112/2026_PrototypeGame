# 2026_PrototypeGame

Unreal Engine 5.8과 C++로 제작 중인 3인칭 콜로니 방어 게임 프로토타입입니다.
외곽에서 진입하는 몬스터와 교전하며 광산 앞 콜로니 코어를 방어합니다.

현재 목표는 **이동·전투 → 마을 방어 → 3웨이브 → 승리·패배 → 다시 시작**이 이어지는 플레이입니다.

## 구현된 기능

- 기존 3인칭 캐릭터를 사용하는 이동·점프·달리기.
- 조준 시 숄더뷰로 전환, 카메라 보간과 조준 중 조준선 표시.
- 두 무기 슬롯: 총의 원거리 판정 / 근접 무기의 범위 판정.
- 플레이어·몬스터 체력, 피격과 사망.
- Behavior Tree / Blackboard / AI Perception 기반 몬스터 추적과 시야 상실 조사.
- 근접 공격의 준비·타격·회복, 거리·방향·가림 검사.
- 광산 앞 콜로니 코어 방어. 플레이어는 코어에 피해를 주지 않습니다.
- 웨이브별 3·5·7마리, 준비 시간과 웨이브 간 대기, 승리·패배 및 재시작.
- 플레이어 체력과 같은 화면 디버그 텍스트로 코어 체력·웨이브·남은 적 수 표시.
- 마을·광산 입구·소굴 입구 5곳을 포함한 임시 맵. 마을 측면의 비행기 충돌 구멍.

## 실행 환경

- Windows 64비트
- Unreal Engine 5.8 (개발 환경: 5.8.4)
- Visual Studio 2022의 C++ 개발 도구와 Windows SDK

1. 프로젝트를 영문 경로(예: `C:\UnrealProjects\2026_PrototypeGame`)에 내려받습니다.
2. `MyProjectPrototype.uproject`의 Visual Studio 프로젝트 파일을 생성합니다.
3. Visual Studio에서 `Development Editor / Win64`로 빌드합니다. 일반 IDE 빌드 시 언리얼 에디터를 먼저 종료합니다.
4. `MyProjectPrototype.uproject`를 열고 기본 맵 `Lvl_ApprovedLayout`에서 Play를 누릅니다.

저장소 이름은 `2026_PrototypeGame`이며, 기존 C++ 모듈과 에셋 참조를 유지하기 위해 언리얼 프로젝트 파일명은 `MyProjectPrototype`을 사용합니다.

## 플레이

| 조작 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Space | 점프 |
| Shift | 달리기 |
| 마우스 오른쪽 | 조준 |
| 마우스 왼쪽 | 공격 |
| 1 / 2 | 총 / 근접 무기 |
| R (승리·패배 후) | 같은 맵 다시 시작 |

코어 체력은 500입니다. 10초 준비 후 적이 정문과 측면 충돌 구멍 바깥에서 번갈아 생성됩니다.
적 생성 간격은 2초, 웨이브 간 대기는 8초이며, 생성 예정인 적도 남은 적 수에 포함됩니다.
3웨이브를 모두 처치하면 승리하고, 플레이어 사망 또는 코어 파괴 시 패배합니다.

## 구조

- `Source/`: C++ 전투·몬스터 AI·콜로니 방어·검증 코드.
- `Config/`: 엔진·입력·시작 맵 설정.
- `Content/`: 캐릭터, 애니메이션, 입력 액션, 몬스터 BP/BT/BB, UI 및 맵 에셋.
- `Docs/`: 범위와 검증 안내.

기존 언리얼 템플릿 에셋과 예제 변형도 에셋 참조 보존을 위해 포함합니다.
빌드 결과, 캐시, 로그, 개인 개발 환경과 작업 백업은 포함하지 않습니다.

## 프로토타입 범위

로컬 1인 플레이 기준입니다. 임시 도형과 기존 템플릿 에셋을 사용합니다.
소굴 5곳은 입구 배치이며, 소굴 던전·보상, 광산 내부, 건설·수리·성장·탈출,
몬스터 종류별 특수 행동과 협동 멀티플레이 동기화는 후속 작업입니다.
